# Image Gallery Project

## How to open in VS Code

1. Download and extract `image-gallery.zip`.
2. Open Visual Studio Code.
3. Select **File → Open Folder**.
4. Choose the extracted `image-gallery` folder.
5. Open `index.html`.
6. Right-click `index.html` and choose **Open with Live Server** if you have the Live Server extension installed.

## Project files

- `index.html` — page structure
- `style.css` — layout, responsive design, hover effects and lightbox styling
- `script.js` — navigation, lightbox, keyboard controls and category filters

## Features

- Responsive CSS Grid
- Image hover effects
- Lightbox view
- Next / Previous navigation
- Keyboard navigation
- Escape key to close lightbox
- Image counter
- Category filtering
- Mobile, tablet and desktop layouts

The images are loaded from Unsplash URLs, so an internet connection is required for the images to appear.
